# WORKSPACE PORTAL — 통합 바로가기

배포 주소: **https://portal.shnboy.workers.dev/**

Cloudflare Worker **`portal`**로 분리 운영. 기존 투자/경매 서비스의 Workers, D1, DB 테이블, Cron 및 코드는 변경하지 않습니다.

## 기본 연결
- 투자: IIR 기술혁신주 / IIR 바이오 혁신주 (같은 앱의 서로 다른 탭)
- 부동산·경매: 경매 레이더 운영 서비스
- 테스트 도구: 경매 지도 미리보기 / 경매 로드뷰 미리보기 (운영 서비스를 대체하지 않음)
- 개발·자료: IIR GitHub 기준서 및 연구 자료

공통 링크는 **`portal/links.json`**에서만 관리합니다. 사이트 카드 제목, 설명, 목적지, 순서, 카테고리 등이 바뀌어도 다른 워커는 배포하지 않습니다.

## 갱신 방법
1. `portal/links.json`에서 실제 공개 URL을 확인한 뒤 항목 추가/수정. 새 서비스는 먼저 실제 배포·접근 가능 여부를 확인합니다.
2. 저장소 루트에서 `node portal/scripts/build.mjs`.
3. `portal/dist/worker.mjs`만 Cloudflare Worker **`portal`**에 배포합니다. 기존 `iir-innovation-radar` 또는 `auction-radar-v02`의 스크립트/환경 변수는 건드리지 않습니다.
4. `https://portal.shnboy.workers.dev/`와 `/health`에서 배포 상태·링크 수를 점검합니다.

빌드 시 최대 60개, 항목 중복, 허용 카테고리, HTTPS URL, 인증정보 포함 URL, 치환되지 않은 템플릿을 검증하고 잘못된 구성이 있으면 배포를 멈춥니다. 포털은 데이터베이스나 관리자 인증정보가 필요 없는 정적 링크 페이지입니다.

## 사용자 편의 기능
- PC/모바일 반응형, 전체 링크 검색, 분류 탭, 즐겨찾기, Ctrl+K 검색
- 기본 포털 링크는 모두 같은 URL에서 제공되어 **기기 간 공통**
- **‘내 링크 추가’와 즐겨찾기는 브라우저의 localStorage에만 저장**. 다른 기기에 자동 동기화하지 않으며 백업/가져오기로 옮길 수 있습니다.
- 로컬 데이터는 서비스 서버에 전송되지 않음. 브라우저 저장 공간을 지우면 삭제될 수 있으므로 개인 링크는 백업 권장.
- 기본 운영 URL과 개발·미리보기 URL을 구분하며 미리보기 링크는 안정적인 운영 기능으로 간주하지 않습니다.

## 향후
출근부, 회계 자동화 등 추가 서비스의 정확한 공개 URL이 확인되면 `links.json`에 등록합니다. 현재 공개 주소를 확인하지 못한 서비스는 임의 링크를 만들지 않습니다.
