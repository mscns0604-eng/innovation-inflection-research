# Innovation Inflection Research (IIR)

**미국 혁신기술주 선행 탐색 연구 / 적용범위 v0.3.0 (배점 RUBRIC v0.2.0) / 최초 작성 2026-11-10**

## 핵심 목표

시장에 이미 알려진 대형 호재를 추격하지 않고 **혁신기술의 기술적·상업적 불확실성이 낮아지는 초기 신호**를 공개정보로 포착해, 아직 주가에 충분히 반영되지 않은 미국 상장사를 찾는다. 미래 상용화 성공과 투자 초과수익은 별도로 측정한다.
