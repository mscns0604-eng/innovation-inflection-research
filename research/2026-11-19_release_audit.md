# IIR 2026-11-19 운영 복구 및 잔여 기능 점검

## 범위와 확인 상태

- 작업 범위: 기존 US-confirmed 활성 후보 TECH 10 + BIO 10 유지, 신규 ABSI·CGEM(BIO) / SLDP·BFLY·ENVX(TECH) 편입.
- 운영 Cloudflare D1 확인: 신규 5종목은 법인 설립국·본사국 US, NYSE/NASDAQ 보통주, 분기 2026Q4 NEW·RESEARCHING. 최종 활성 TECH 13 + BIO 12 = 25개.
- 변경 파일: `app/migrations/0009_q4_five_additional.sql`, `app/migrations/0010_sec_scan_coverage.sql`, `app/worker.js`, `app/web.html`, `app/tests/worker.test.mjs`.
- 신규 D1 마이그레이션은 운영에 반영되었고 기존 공시·과거가격·수동평가 및 제외 이력은 삭제하지 않았다.
- 새 후보의 시장 종가, 검증된 자발적 매수, 점수는 임의로 채우지 않았다. 추가 데이터는 정기 수집의 다음 성공 시점에 날짜와 함께 들어온다.
- 기존 운영 정기 Cron은 2026-11-19 08:30 KST 실행 기준 SEC 및 종가 작업이 SUCCESS. **이는 신규 25개 목록과 변경 코드가 전 기업을 검사한 기록은 아니다.**
- 마지막 별도 검증 시각의 D1 최신 종가는 기존 20개 대상, US 정규장 2026-11-18 기준이었다. 25개 가격 수집 완료를 주장하지 않는다.

## 개선·복구된 사항

1. **후보 편입과 지역 자격:** 기존 20개를 보존한 채 5개 US-confirmed 신규 기업을 분기 목록에 추가. DB migration 재실행은 `INSERT OR IGNORE` 기반이므로 동일 후보 중복 삽입을 피한다.
2. **신규 후보 차트:** 고정된 20개 티커 사전 대신, 종목별 증빙된 `primary_exchange` 정보를 사용해 TradingView 상장 거래소 심볼을 구성한다. 다만 제3자 사이트에서 실제 렌더링된 차트는 제공사/브라우저에 의존한다.
3. **바이오 임상 링크:** ABSI NCT07317544 / CGEM NCT05143996 연결과 상세뷰의 임상 등록정보 목록을 추가. 등록 자체가 임상 성공 또는 모집 상태의 당일 검증을 뜻하지 않는다.
4. **SEC 수집 진행상태:** `company_sec_scan_state`에 기업별 SEC Form 4 최근 검사 성공 시각·고려 문서수·신규 코드 P 행수·오류를 저장. 최초 도입 직후 비어 있고 새 Worker가 기업별 순회하며 작성한다. 최대 최근 2건 검색이므로 '매수 없음'으로 단정하지 않는다.
5. **내부자 금액 분리:** 과거 수동 발굴의 매수 추정금액과 실제 DB 내 Form 4 코드 P 취득 신고금액을 구분해 노출한다. 코드 P는 장내 자발적 현금매수와 동의어가 아니다.
6. **보수적 안전 동작:** SEC 호출량·총시간·재시도 제한, D1 lease, checkpoint, 중복 접수번호 방지, 401/403/429 즉시 중단을 유지. 오래된 정상 데이터는 실패 시 보존.
7. **배포 안전성:** Cloudflare 비밀변수 `SEC_CONTACT_EMAIL`을 `inherit`/strict 방식으로 승계하고 기존 D1·Cron을 보존. 관리자 토큰을 임의 생성하거나 공개 저장소에 넣지 않음.

## 후속 검증 기준

- Github Actions의 `IIR application tests` Node 테스트 전체 성공.
- Cloudflare Worker **운영 배포 버전 100%** 여부와 기존 D1·`SEC_CONTACT_EMAIL` 상속 확인.
- 공개 후보 API TECH 13 + BIO 12, 새 5개 상세 및 NCT 참조, 수집 진행/시장 가격 기준일 검사.
- *신규 25개 전체 Cron 통과*는 다음 자동 실행 뒤 `pipeline_runs`, `pipeline_state`, `company_sec_scan_state`, `market_snapshots`로 확인해야 한다. 이 점검이 끝나기 전까지 25개 전체 자동수집 복구를 선언하지 않는다.
- 위 실패 항목을 덮기 위해 더미 가격·내부자 매수·확정 임상 결과·수치점수를 생성하지 않는다.
