## 평가의 핵심 규칙

- 본 문서는 **수동 정성평가/자동화 설계 검증용**이며, 주식 매수 권고나 전체 100점 확정 순위가 아님. 순번은 **당장 확인할 가치가 있는 연구 우선순위**이며 실제 진입 매력 순위가 아님.
- 7개 배점(내부자25·테마20·기술20·외부검증10·재무10·가격10·매크로5)을 준수하되, 각 영역 세부 조건(10b5-1, 독립 내부자, 희석후 가치, 정상가격, 고객 독립검증, VIX/금리 변화)이 아직 채워지지 않아 숫자를 생성하면 허위 정밀도가 생김. **10개 모두 100점 숫자/미확인 항목 = NULL 유지.**
- 기존 `companies` 2026-11-09 금액과 시세는 역사적 스냅샷이므로 손대지 않고 `score_snapshots`에 2026-11-10 미국장 종료 시점의 **별도 평가**를 적재.
- **주가 계산:** Yahoo Finance Chart v8의 미국 거래소 일별 `quote.close`를 사용해 마지막 종가 / 20, 60, 120 거래일 전 종가 - 1 (가격 수익률, 배당 재투자 미포함; 제공사의 분할보정 처리 기준을 따름). 251개 유효 일봉 관측, 2026-11-10까지, 거래소 현지 날짜. 값은 비교 참고값이며 재배포 가격 DB는 미구축. 값이 잘못 정정되면 같은 컷오프의 소스/원본 검증 필요.
- 동일 회사의 신고자 ID(CIK)와 회사 ID(CIK)를 혼동하지 않을 것. 특히 ANIX의 회사 CIK는 **0000715446**이고 Titterton 신고자 CIK는 **0001499254**이므로 과거 D1 혼동 오류를 정정.
- 공시의 `P` 코드는 매수 표시에 가깝지만 **시장자발매수/사전계획매매를 아직 확정하지 않음**. 같은 사람 반복 구매를 추가 독립 참여자로 계산하지 않음.

### 구현 우선순위

1. **정합성 검증 파이프라인:** 회사 CIK/내부자 CIK 구별, 공개시각과 원문 뷰/교정, 등록자료 수정 이력, 수집 실패시 safe-stop. 외부 원문이 없으면 `UNVERIFIED`.
2. **금융 데이터 1차 자동화:** 분기 재무제표에 SEC 10-K/10-Q/20-F/6-K 분류, 잔존현금·ATM/S-3·부채 데이터를 수집하고 사람용 보수적 경보 생성.
3. **이벤트 기반 갱신:** Form 4 독립매수자/일정, 기술 실증/계약 단계, 가격 20/60/120일 및 공시 직전/직후 수익률, 매크로를 같은 시점으로 정렬. 가격 이용계약을 확인한 제공사만 DB 저장.
4. **근거형 평가 초안:** 100점 수치는 7영역의 필수 검증 증거가 있는 것만 입력. 현재는 정성적 연구순위와 진입적합성을 분리하여 화면에 표시.
5. **사람 검토 워크플로:** 개별 소스 링크/확인 필요 목록/수정 사유/승인자·승인시각. 검증되지 않은 사실을 자동 매수 추천으로 승격하지 않음.

### 안전장치

- 최대 종목 수, API 요청 수, 총 처리시간, 요청별 타임아웃·재시도 상한.
- D1 체크포인트, filing accession·owner/date/sequence 중복 차단, 소스별 날짜/품질 상태 기록.
- 원문 불일치·중복 CIK·예상하지 못한 API 응답·주가 구간분할 오류 → 해당 종목의 수치 확정 **중지하고 검증 대기**.
- 과거 연구 및 평가 결과는 불변 스냅샷. 새 평가에는 `asof_utc`와 `rubric_version` 기록. 자동매매 기능은 별도 명시 승인 없이는 추가하지 않음.
